# Java Matrix Sum Assignment

A simple Java program that takes a square matrix as input and calculates the sum of each row, each column, and both diagonals.

## 📋 Features

- Accepts matrix size and elements as user input
- Calculates and displays:
  - Sum of each row
  - Sum of each column
  - Sum of the main diagonal
  - Sum of the secondary (anti) diagonal
- Simple console-based output

## 🛠️ Tech Used

- Java (Core Java, 2D Arrays, Loops)

## 🚀 How to Run

1. Clone this repository
```bash
   git clone https://github.com/muhammadsufyan13/Java-Assignment.git
```
2. Compile the program
```bash
   javac MatrixSum.java
```
3. Run it
```bash
   java MatrixSum
```
